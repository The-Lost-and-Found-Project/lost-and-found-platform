# L&F Live release checklist

A Live change is not production-ready until:

- Vercel preview succeeds.
- Gather, Teach, and Discuss are usable on desktop and mobile.
- Camera and microphone remain stable through mode and panel navigation.
- Full Screen remains stable.
- Facilitator-only material stays private.
- End Study closes the live session and returns the facilitator cleanly.
- Daily Path release behavior is verified separately from the visual room controls.
