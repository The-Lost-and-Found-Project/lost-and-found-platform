# L&F Live finishing pass

Principle: advanced underneath, simple on the surface.

## Locked interaction rules
- Gather, Teach, and Discuss never change mic or camera state.
- Facilitator Notes, Tools, and Prayer are private and collapsed by default.
- A facilitator opens a panel intentionally and can toggle it closed from the same control.
- Changing room mode closes the private panel so the next mode begins visually clean.
- Changing slides preserves an open panel only when that panel has authored content on the new slide; otherwise it closes automatically.
- Teach does not force Notes open.
- Empty facilitator content never takes permanent study space.
- Full Screen remains display-only and does not own Daily media or study state.
